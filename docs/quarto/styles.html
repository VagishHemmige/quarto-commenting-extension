4. Styles

Author

Vagish Hemmige

The stylesheet gives the buttons and dialog a look that fits the site. Every class starts with ic-, so it cannot clash with the site’s own styles.

Source code

_extensions/issue-comments/issue-comments.css

Following the site’s theme

Colours come from the Bootstrap variables that Quarto’s HTML themes define (--bs-body-bg, --bs-primary and so on), each with a fallback. So the buttons and dialog take on the site’s theme, including a dark theme, and still look reasonable on a page without Bootstrap.

Buttons

Both buttons are rounded “pills” with a light shadow. The selection button is placed absolutely, at the position the script calculates; the page button is fixed to the bottom right of the window. A z-index of 1050 puts them above Bootstrap’s fixed navigation bar, which uses 1030.

_extensions/issue-comments/issue-comments.css, lines 1–18

.ic-select-btn,
.ic-page-btn {
  font: inherit;
  font-size: 0.85rem;
  border: 1px solid var(--bs-border-color, #ccc);
  background: var(--bs-body-bg, #fff);
  color: var(--bs-body-color, #222);
  border-radius: 999px;
  padding: 0.3rem 0.8rem;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);
  cursor: pointer;
  z-index: 1050;
}
.ic-select-btn { position: absolute; }
.ic-page-btn { position: fixed; right: 1rem; bottom: 1rem; }
.ic-select-btn:hover,
.ic-page-btn:hover { border-color: var(--bs-primary, #2780e3); }
.ic-select-btn[hidden] { display: none; }

The [hidden] rules matter because a display value set by a stylesheet overrides the browser’s built-in handling of the hidden attribute, which the script uses to show and hide things.

The dialog

The dialog is at most 34rem wide, and narrower on small screens. The backdrop dims the page behind it.

_extensions/issue-comments/issue-comments.css, lines 20–28

.ic-dialog {
  width: min(34rem, calc(100vw - 2rem));
  border: 1px solid var(--bs-border-color, #ccc);
  border-radius: 0.5rem;
  padding: 1.25rem;
  background: var(--bs-body-bg, #fff);
  color: var(--bs-body-color, #222);
}
.ic-dialog::backdrop { background: rgba(0, 0, 0, 0.35); }

The heading’s border and padding are reset because Quarto themes add a rule under h2. Labels sit above full-width fields.

Passage, notes and the honeypot

The quoted passage keeps its line breaks and scrolls once it is taller than 9rem. The honeypot field is moved far off-screen rather than hidden with display: none, because bots may skip fields that are not displayed.

  overflow: auto;
  margin: 0.5rem 0;
  padding: 0.4rem 0.75rem;

  background: var(--bs-tertiary-bg, #f6f6f6);

Printing

The buttons and dialog are hidden when a page is printed.

_extensions/issue-comments/issue-comments.css, lines 91–93

@media print {
  .ic-select-btn, .ic-page-btn, .ic-dialog { display: none !important; }
}
